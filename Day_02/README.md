# 💻 Setting Up VS Code for Python

Today we will install **VS Code** and make it ready for Python programming 🐍

---

# 🤔 What is VS Code?

VS Code (Visual Studio Code) is a code editor.

👉 Programmers use it to write code easily.

It helps us:
- write code
- run programs
- fix mistakes
- organize files

---

# 📥 Step 1: Download VS Code

1. Open your browser
2. Go to:

`https://code.visualstudio.com/`

3. Click the big button:

👉 `Download for Windows`

---

# 📂 Step 2: Open the Installer

1. Go to your **Downloads** folder
2. Double click the VS Code installer

---

# ⚙️ Step 3: Important Checkboxes

While installing, make sure these are checked ✅

- Add "Open with Code" action
- Add to PATH

These help VS Code work better.

---

# 🛠️ Step 4: Install VS Code

Click:

👉 `Next`
👉 `Install`

Wait for installation to finish.

Then click:

👉 `Finish`

---

# 🚀 Step 5: Open VS Code

Open VS Code from:
- Desktop icon
OR
- Windows Search

---

# 🐍 Step 6: Install Python Extension

This step is VERY IMPORTANT.

Python extension helps VS Code understand Python code.

Without this extension:
- Python code may not run properly
- Syntax colors may not appear
- Run button may not work correctly

---

## 🔹 Open Extensions

1. Look at the left side of VS Code
2. Click the Extensions icon

It looks like this:

🧩

---

## 🔹 Search for Python

At the top, you will see a search box.

Type:

```python
Python
```

---

## 🔹 Install Python Extension

You will see many extensions.

Find the one:
- named `Python`
- made by `Microsoft`

Then click:

👉 `Install`

---

## 🔹 Wait for Installation

Wait a few seconds for installation to complete.

You may see:
- Installing...
- Installed ✅

---

## 🔹 Restart VS Code (If Needed)

Sometimes VS Code may ask to restart.

If it does:
👉 Click `Restart`

---

# 📁 Step 7: Open Your Python Folder

1. Click:

`File → Open Folder`

2. Choose your Python folder

Example:
- Desktop/Python
- Documents/Python

---

# ✍️ Step 8: Create Python File

Click:

`File → New File`

Save file as:

```python
hello.py
```

---

# 🧠 Step 9: Write Your First Program

```python
print("Hello from VS Code! 🚀")
```

Save the file.

---

# ▶️ Step 10: Run the Program

Click the small ▶️ Run button on top right.

OR

Right click inside file → Click:

`Run Python File`

---

# 🎉 Success!

If you see:

```python
Hello from VS Code! 🚀
```

🎉 Your VS Code setup is complete!

---

# 💡 Helpful Tips

## Save File Quickly

Press:

```python
Ctrl + S
```

---

## Open Terminal

Press:

```python
Ctrl + `
```

This opens the terminal inside VS Code.
