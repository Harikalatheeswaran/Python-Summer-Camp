## 🐍 Python Installation Guide (Windows)

Follow these simple steps to install Python on your Windows computer. Don’t worry—just go step by step!

---

### 📥 Step 1: Go to the Python Website

1. Open your web browser (like Chrome, Edge, or Firefox).
2. Go to this link: [https://www.python.org/](https://www.python.org/)

---

### ⬇️ Step 2: Download Python

1. On the homepage, look for the **“Downloads”** button.
2. Click on it.
3. You should see a big yellow button that says something like:
   👉 **Download Python (latest version)**
4. Click that button to start downloading.
5. Or use this link to download : https://www.python.org/ftp/python/3.14.4/python-3.14.4-amd64.exe

---

### 📂 Step 3: Open the Installer

1. Once the download is finished:

   * Go to your **Downloads** folder.
2. Find the file you just downloaded (it will start with `python` and end with `.exe`).
3. Double-click the file to open it.

---

### ⚙️ Step 4: Important Checkbox! (Very Important 🚨)

Before clicking install:

✅ Look at the bottom of the installer window
✅ Check the box that says:

```
Add Python to PATH
```

👉 This step is VERY important. Do not skip it!

---

### 🛠️ Step 5: Install Python

1. After checking the box, click:

   👉 **Install Now**

2. Wait for the installation to finish (this may take a few minutes).

---

### ✅ Step 6: Finish Installation

1. When it’s done, you’ll see a message like:

   ✔️ *Setup was successful*

2. Click **Close**

---

### 🧪 Step 7: Check if Python Works

Let’s make sure everything is working!

1. Press `Windows Key + R`
2. Type:

```
cmd
```

3. Press Enter (this opens the Command Prompt)

4. In the black window, type:

```
python --version
```

5. Press Enter

👉 If you see something like:

```
Python 3.x.x
```

🎉 Congratulations! Python is installed successfully!

## 🐍 Bonus: Run Your First Python Program

1. In the same Command Prompt, type:

```
python
```

2. Press Enter

3. Now type:

```python
print("Hello, world!")
```
🎉 You just ran your first Python program!

# 📁 Creating Your First Python File

Create a file named:

`hello.py`

Add this code:

```python
print("Hello 😊")
print("I love Python 🐍")
print("Meow 🐱")
print(":)")
```

Save the file.

---

# ▶️ Running Python File Using IDLE

1. Right click the file
2. Open with **IDLE**
3. Press:

`F5`

Your program will run 🎉

---

# 💻 Running Python File Using CMD

This is how developers run files 😎

## Step 1: Open CMD in Current Folder

- Go to the folder where `hello.py` is saved
- Click the address bar
- Type:

`cmd`

- Press Enter

CMD opens directly in your current folder.

---

## Step 2: Check Files in Folder

Type:

`dir`

This shows all files in that folder.

You should see:

`hello.py`

---

## Step 3: Run Your Python File

Type:

`python hello.py`

Your file runs 🎉
